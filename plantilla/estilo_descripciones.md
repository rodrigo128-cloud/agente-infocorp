# Estilo de descripciones Infocorp

Formato tomado del catálogo de Infocorp. Todas las descripciones siguen estas reglas.

## Reglas generales

- Todo en MAYÚSCULAS. Máximo ~50 caracteres por línea (sin contar comillas de pulgadas).
- Orden: `CATEGORÍA + MARCA + CÓDIGO/NÚMERO DE PARTE + MODELO + ESPECIFICACIONES CLAVE + COLOR`.
- El código o número de parte va siempre que se conozca (ej. `910-004940`, `LS32D396GANXZA`).
- Especificaciones separadas por espacio o por `/` (en notebooks y PCs, siempre `/`).
- Sin tildes ni la palabra "de" salvo cuando es parte del nombre (`FILTRO DE LINEA`, `MOUSE PAD`).

## Prefijos de categoría

| Producto | Prefijo |
|---|---|
| Notebook | `NB` |
| Placa madre | `MB` (ej. `MB ASUS PRIME D4 LGA1700 HDMI/VGA/M.2`) |
| Memoria RAM | `MEM` sin número de modelo (ej. `MEM DDR4 16GB 3200MHZ FTX`) |
| SSD | `HDD SSD` sin número de modelo (ej. `HDD SSD 512GB M.2 NVME KEEPDATA`) |
| Gabinete kit | solo hasta el modelo (ej. `GAB. KIT SATELLITE K701`) |
| PC de escritorio / AIO / mini PC | `PC` / `PC ... AIO` / `MINI PC` |
| Monitor | `MON 32"` (el tamaño va pegado al prefijo) |
| Impresora | `IMP` (`IMP HP LASER ...`, `IMP EPSON L ...`) |
| Escáner | `SCANNER` |
| UPS | `UPS` |
| Mouse | `MOUSE` |
| Mouse pad | `MOUSE PAD` |
| Teclado / combo | `TECLADO` (combo: `TECLADO ... COMBO WIR`) |
| Auricular / headset | `AURI` |
| Parlante | `PARLANTE` |
| Webcam | `CAM WEB` |
| Cámara de seguridad | `CAM` |
| Disco interno / externo / SSD | `HDD` / `HDD EXT` / `HDD SSD` |
| Memoria / micro SD / pendrive | `MEM` |
| Zapatilla / filtro | `FILTRO DE LINEA` |
| Maletín / mochila | `MALETIN` / `MOCHILA` |
| Cable / adaptador / hub | `CABLE` / `ADAPTADOR` / `HUB` |

| Tóner / tinta | `TONER` / `TINTA` |

## Abreviaturas de marca

`LOGIT` (Logitech), `MICRO` (Microsoft), `EP` (Epson, en consumibles y accesorios; `EPSON` en equipos), `DH` (Dahua), `VERB` (Verbatim), `BELK` (Belkin), `ARG` (Argom), `SAT` (Satellite), `HPE` (HP Enterprise). Las demás marcas van completas: `HP`, `ACER`, `ASUS`, `SAMSUNG`, `VIEWSONIC`, `BROTHER`, `MSI`, `LENOVO`, `DELL`, `TOSHIBA`, `SEAGATE`, `KINGSTON`.

## Abreviaturas técnicas

`WIR` (inalámbrico/wireless), `WIF` (wifi), `BT` (bluetooth), `GAM` (gaming), `C/` (con), `P/` (para), `S/` (sin), `MFP` (multifunción), `MONO`, `COLOR`, `DUPLEX`, `ADF`, `FHD`, `QHD`, `4K`, `UHD`, `IPS`, `CURVO`, `HZ`, `V.A.`, `KVA`, `TB`, `GB`.

## Notebooks (formato obligatorio)

`NB MARCA LÍNEA PROCESADOR/RAM/ALMACENAMIENTO/PANTALLA/SO/GPU VRAM`

Ejemplo de referencia:
`NB ACER PREDATOR HELIOS NEO ULTRA 9-275HX/32GB/1TBSSD/16"/W11/RTX5070TI 12GB`

- **Marca y línea** (nombre comercial, sin número de parte): `HP VICTUS`, `HP 15`, `HP OMNIBOOK 5`, `ACER NITRO V`, `ACER PREDATOR HELIOS NEO`, `ASUS VIVOBOOK`, `ASUS ROG STRIX G16`, `MSI VECTOR 16`, `LENOVO IDEAPAD SLIM 3`, `DELL INSPIRON`.
- **Procesador:** Intel Core `CI3`/`CI5`/`CI7`/`CI9` con el modelo (`CI7-13620H`, `CI5-1334U`); Intel Core Ultra `ULTRA 5`/`ULTRA 7`/`ULTRA 9` con el modelo (`ULTRA 9-275HX`); Intel Core de la serie nueva sin "i" `CORE 5-120U`; AMD `R5-7520U`, `R7-7445HS`, `R9-8945HX`; Celeron `CEL N4500`.
- **RAM:** con `GB`: `8GB`, `16GB`, `32GB`.
- **Almacenamiento SSD:**
  - Hasta 512 GB: el número y `SSD`, sin "GB": `256SSD`, `512SSD`.
  - Desde 1 TB: con `TB`: `1TBSSD`, `2TBSSD`.
  - Disco mecánico adicional: `512SSD+1TBHDD`.
- **Pantalla:** en pulgadas con comillas: `15.6"`, `16"`, `18"`.
- **SO:** `W11`, `W11 PRO`, `W10`, `FREE DOS`, `LINUX`.
- **GPU dedicada** (solo si tiene): `RTX5070TI 12GB`, `RTX4050 6GB`, `RTX3050 6GB`. Sin GPU dedicada, la descripción termina en el SO.
- Color al final solo si el cliente lo pide o hay varias opciones de color.

Más ejemplos:
- `NB HP 15 CI5-1334U/8GB/512SSD/15.6"/W11`
- `NB HP OMNIBOOK 5 CI5-1334U/8GB/512SSD/16"/W11`
- `NB HP VICTUS CI7-13620H/16GB/512SSD/15.6"/W11/RTX5060 8GB`
- `NB MSI VECTOR 16 ULTRA 9-275HX/32GB/2TBSSD/16"/W11/RTX5080 16GB`
